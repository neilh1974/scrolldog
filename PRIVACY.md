# Privacy

Scroll Dog does not collect personal data.

## Data Stored

Scroll Dog stores only local scroll totals per supported site host. The data stays in browser extension storage on the device.

Stored fields:

1. Host name
2. Scroll distance
3. Last update time

## Data Not Collected

Scroll Dog does not collect page text, account details, profile data, messages, posts, photos, browsing history, or device identifiers.

## Network Use

Scroll Dog does not send extension data to any server.

## Reset

The popup has a reset control that clears Scroll Dog local stats.

## Store Privacy Answer

For App Store Connect privacy, answer that the app does not collect data.
